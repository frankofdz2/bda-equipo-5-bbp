# Datos utilizados

Los ejemplos `bbp` y `distbbp` de Hadoop 3.3.6 no requieren cargar archivos CSV ni conjuntos de datos externos para esta práctica.

Los datos de entrada son los parámetros de ejecución: posición inicial, cantidad de dígitos o bits, tareas y directorios. El propio programa construye las particiones matemáticas necesarias para realizar el cálculo.

Las salidas y los archivos parciales se documentan en [resultados](../resultados/).
